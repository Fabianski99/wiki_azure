# Wiki Azure

Wiki educativa sobre Microsoft Azure y seguridad de la información.

## Stack
React + Vite, JavaScript y CSS responsive.

## Ejecutar
```bash
npm install
npm run dev
```

## Compilar
```bash
npm run build
```

El contenido distingue las configuraciones trabajadas en laboratorio de las recomendaciones de ampliación. Material educativo general: valida siempre los controles según el contexto y la documentación oficial de Microsoft.
